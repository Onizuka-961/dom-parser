# dom-parser

A minimal browser extension that extracts the full DOM of the active page.

## Install (Chrome / Chromium)

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select the local folder containing this repository.

## Usage

1. Open any webpage.
2. Click the extension icon.
3. Click **Extract DOM**.
4. Review the DOM in the textarea.
5. Optionally click **Download .html** to save it.
